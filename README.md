# 訳す (yakusu)

A no-install translate bookmarklet. Click it on any Japanese web page and the text turns into English right where it sits — same layout, same buttons, same login. Click again to toggle back to Japanese.

Install page: https://gutsmcd-cmd.github.io/yakusu/

Note: page text is sent to Google Translate to be translated, so don't use it on confidential pages.
